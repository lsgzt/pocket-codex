HOW TO SIGN FUTURE UPDATES
--------------------------------------
The project already wires this keystore in through
PocketDev/keystore.properties (git-ignored). To rebuild:

    cd pocket-codex/PocketDev
    ./gradlew assemblePyRelease

Output: app/build/outputs/apk/py/release/app-py-release.apk

To sign an unsigned APK manually:

    apksigner sign --ks pocketdev-release.keystore \
        --ks-key-alias pocketdev \
        --out app-signed.apk app-unsigned.apk

IMPORTANT: Always sign updates with THIS keystore. Android only installs an
update if it is signed with the same key as the installed version — losing
this keystore means users would have to uninstall/reinstall the app.

Verify a signature:

    apksigner verify --print-certs PocketDev-v1.1.0-release.apk
